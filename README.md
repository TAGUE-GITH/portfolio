# Franck Tague · Portfolio

Portfolio de **Franck Tague**, développeur full-stack Java, Python et React, en recherche d'une alternance de 24 mois
à partir d'octobre 2026.

Il présente cinq applications en ligne réalisées pour de vraies entreprises :

| Projet | Description | Technologies |
|---|---|---|
| [DITS Group](https://dits-frontend.vercel.app) | Plateforme d'une société de conseil (stage) : vitrine, espace client, recrutement, administration | Spring Boot, PostgreSQL, React |
| [FloreEvent](https://flore-event.vercel.app) | Location événementielle (Melun) : disponibilités, devis, acompte Stripe, factures PDF, logistique | Spring Boot, PostgreSQL, React, TypeScript |
| [MilaTech Management](https://milatech-one.vercel.app) | Gestion d'une boutique d'électronique : caisse, stock, réparations, formations, boutique en ligne | Spring Boot, PostgreSQL, React, TypeScript |
| [DevManager](https://devmanager-five.vercel.app) | SaaS de gestion d'entreprise multi-entreprises, web et Android | Spring Boot, React, React Native (Expo) |
| [ShoeManager](https://shoe-manager.vercel.app) | Boutique de chaussures (Douala) : boutique en ligne, stock par pointure, caisse | Django REST, PostgreSQL, React |

## Le site

- React 19, TypeScript, Vite, Tailwind CSS
- Français et anglais (bouton FR / EN, choix mémorisé)
- Responsive (téléphone, tablette, ordinateur) et accessible (navigation au clavier, textes alternatifs)
- Tests : Vitest et Testing Library

```bash
npm install
npm run dev     # http://localhost:5173
npm test
npm run build
```

Hébergé sur Vercel.
